# Forum Bot — Бот для Форум-группы предпринимателей

Telegram-бот для автоматического отслеживания обещаний участников в закрытой Форум-группе.

## Описание

Бот слушает сообщения в группе, с помощью ИИ определяет, является ли сообщение обещанием, и предлагает его зафиксировать. Раз в неделю отправляет личные напоминания о незакрытых обещаниях. За день до Форума напоминает участникам заполнить тетрадь.

## Функции

- **Автоопределение обещаний** — ИИ (OpenAI или Anthropic) анализирует каждое сообщение в группе
- **Фиксация обещаний** — участник подтверждает, редактирует или отклоняет предложение бота
- **Еженедельные напоминания** — личные сообщения с активными обещаниями каждый понедельник (или другой день)
- **Напоминания о Форуме** — за день до Форума бот напоминает заполнить тетрадь
- **Команды участника** — просмотр, выполнение, отмена обещаний
- **Команды модератора** — просмотр всех обещаний, установка даты Форума, ручной запуск напоминаний

## Переменные окружения

Скопируй `.env.example` в `.env` и заполни:

| Переменная | Описание | Обязательная |
|-----------|----------|:------------:|
| `BOT_TOKEN` | Токен бота от @BotFather | ✅ |
| `DATABASE_URL` | URL базы данных PostgreSQL (asyncpg) | ✅ |
| `GROUP_CHAT_ID` | ID группового чата (отрицательное число) | ✅ |
| `MODERATOR_TELEGRAM_ID` | Telegram ID модератора | ✅ |
| `AI_PROVIDER` | `openai` или `anthropic` | — (openai) |
| `OPENAI_API_KEY` | Ключ OpenAI API | ✅ если `AI_PROVIDER=openai` |
| `OPENAI_MODEL` | Модель OpenAI | — (gpt-4.1-mini) |
| `ANTHROPIC_API_KEY` | Ключ Anthropic API | ✅ если `AI_PROVIDER=anthropic` |
| `ANTHROPIC_MODEL` | Модель Anthropic | — (claude-3-5-sonnet-latest) |
| `TIMEZONE` | Часовой пояс | — (Europe/Moscow) |
| `WEEKLY_REMINDER_DAY` | День недели для напоминаний | — (MONDAY) |
| `WEEKLY_REMINDER_TIME` | Время для напоминаний (HH:MM) | — (10:00) |
| `LOG_LEVEL` | Уровень логирования | — (INFO) |

Пример `DATABASE_URL`:
```
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/forumbot
```

## Создание Telegram-бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Придумай имя и username бота
4. Скопируй токен в `BOT_TOKEN`
5. Отправь `/setcommands` и задай команды:
```
start - Начало работы
help - Помощь
my_promises - Мои активные обещания
done - Отметить выполненным
cancel - Отменить обещание
```

## Отключение Privacy Mode

Чтобы бот видел все сообщения в группе (не только команды):

1. Открой [@BotFather](https://t.me/BotFather)
2. Отправь `/mybots`
3. Выбери своего бота
4. `Bot Settings` → `Group Privacy` → `Turn off`
5. Убедись что показывает **DISABLED**

## Добавление бота в группу

1. Открой группу → Добавить участника → найди своего бота
2. Дай боту права администратора (минимум: читать сообщения)
3. Бот должен видеть все сообщения (Privacy Mode отключён)

## Получение GROUP_CHAT_ID

Способ 1 — через бота:
1. Добавь [@userinfobot](https://t.me/userinfobot) в группу
2. Напиши `/start` в группе — он покажет ID группы (отрицательное число)

Способ 2 — через getUpdates:
1. Напиши `/start` в группе
2. Открой `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. Найди `"chat": {"id": ...}` — это и есть `GROUP_CHAT_ID`

## Получение MODERATOR_TELEGRAM_ID

1. Открой [@userinfobot](https://t.me/userinfobot) в личных сообщениях
2. Отправь `/start` — он покажет твой Telegram ID

## Локальный запуск

### Требования
- Python 3.11+
- PostgreSQL 14+

### Установка

```bash
# Клонировать репозиторий
git clone <repo>
cd forum-bot

# Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt

# Скопировать и заполнить .env
cp .env.example .env
# Отредактировать .env
```

### Применение миграций

```bash
alembic upgrade head
```

### Запуск

```bash
python -m app.main
```

## Деплой на Railway

1. Создай аккаунт на [Railway.app](https://railway.app)
2. Создай новый проект → Deploy from GitHub repo
3. Добавь PostgreSQL сервис в проект
4. Скопируй `DATABASE_URL` из PostgreSQL сервиса
5. Добавь все переменные окружения в Settings → Variables
6. Убедись что `DATABASE_URL` использует `postgresql+asyncpg://` схему
7. Деплой запустится автоматически

Для запуска миграций на Railway:
- Добавь Custom Start Command: `alembic upgrade head && python -m app.main`

Или создай отдельный Railway сервис для миграций.

## Частые проблемы

### Бот не видит сообщения в группе
- Убедись что Privacy Mode отключён в BotFather
- Проверь что бот добавлен как участник группы
- Проверь что `GROUP_CHAT_ID` указан правильно (отрицательное число)

### Ошибка подключения к БД
- Проверь что PostgreSQL запущен
- Убедись что `DATABASE_URL` использует `postgresql+asyncpg://` схему
- Проверь логин/пароль и имя базы данных

### ИИ не анализирует сообщения
- Проверь `AI_PROVIDER` (openai или anthropic)
- Убедись что соответствующий API ключ заполнен
- Посмотри логи на ошибки API

### Бот не отвечает на команды
- Убедись что бот запущен (`python -m app.main`)
- Проверь `BOT_TOKEN`
- Посмотри логи на ошибки
